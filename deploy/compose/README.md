# deploy/compose

Docker Compose stack for pilots (spec 5.5): PostgreSQL, ClickHouse, `ingest-api`, `edge-gateway`,
the OpenTelemetry Collector, one-shot `pki-init`, `key-init` and `migrate` jobs, and the
simulator in live mode under the `dev` profile. The reverse proxy, `api`, `web` and the workers
join in M2 to M4; Helm in M6.

```
make dev                                   # build images, generate secrets, start the stack with the simulator
docker compose -f deploy/compose/compose.yaml logs -f edge-gateway ingest-api
docker compose -f deploy/compose/compose.yaml down -v
```

Hardening applied to every service (spec 14.6): read-only root filesystem, all capabilities
dropped, `no-new-privileges`, non-root user, internal networks only (nothing publishes a port
until the reverse proxy arrives). `sources.dev.yaml` points the edge at the simulator's output
volume; copy it to `sources.yaml` and edit for a real pilot (see `docs/install/compose-pilot.md`).

`secrets/pg_password` and `secrets/ch_password` are generated by `make dev` when missing and are
git-ignored.
